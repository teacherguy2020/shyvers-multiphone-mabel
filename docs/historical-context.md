# Historical context

The Shyvers Multiphone was a paid request terminal connected to a central
music service. A customer inserted a coin, contacted an operator, requested a
record, and then received the program audio through the establishment's sound
system.

The modern projects preserve that separation of concerns:

| Historical role | Modern relationship |
| --- | --- |
| Customer request terminal | Multiphone/Mabel system |
| Central operator | Mabel and its local service flow |
| Printed catalog | Digital catalog and validated requests |
| Operator queue | Now Playing integration |
| Program audio | Existing room playback system |

This document provides context only. Current implementation and operational
behavior should be verified against the owning project repository.
