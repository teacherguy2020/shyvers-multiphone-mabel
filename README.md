# Shyvers Multiplayer

Repository for the Shyvers Multiplayer project.

This repository is intentionally separate from the `now-playing` repository,
which contains the Multiphone/Mabel runtime and hardware trigger. Project
source and deployment files will be added here as the multiplayer system is
organized.

## Security

Keep API keys, passwords, tokens, certificates, and machine-specific
configuration outside Git. Use local environment files or the deployment
platform's secret store, and commit only sanitized example configuration.
